## Mini-projeto: Análise Exploratória da Base Varejo

### O que fazer

1. Abra este projeto no **VSCode** (ou no **Google Colab**).
2. Certifique-se de que os arquivos `eda_varejo.py` e `Base_varejo.csv` estão na mesma pasta.
3. No VSCode, abra um terminal e instale as dependências:
   ```bash
   pip install pandas numpy
   ```
4. Execute o script:
   ```bash
   python eda_varejo.py
   ```

### No Google Colab

1. Faça upload de `eda_varejo.py` e `Base_varejo.csv`.
2. Rode todas as células ou execute:
   ```bash
   !python eda_varejo.py
   ```

### Saída esperada

O script imprime no console, organizado por sprints:

- Sprint 1: importação da base (registros, colunas, tipos).
- Sprint 2: transformação de tipos (texto com regex, numérico, datetime).
- Sprint 3: limpeza de nulos e duplicatas.
- Sprint 4: estatísticas descritivas de `CL_FHL` (número de filhos).
- Sprint 5: relatório final, agrupamentos, contadores e conclusões.
- Sprint 6: versionamento via Git/GitHub (realizado externamente ao script).
